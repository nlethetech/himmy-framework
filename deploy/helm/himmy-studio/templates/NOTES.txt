2. Loopback-guard reminder:

   The /api/studio paths are guarded. Requests are allowed only when the Host
   header is loopback (localhost / 127.0.0.1 / ::1 / testserver — always
   allowed) OR is listed in HIMMY_STUDIO_ALLOW_HOSTS. /health is UNGUARDED.

{{- if .Values.ingress.enabled }}
   This chart automatically adds every ingress host to the allow-list, so the
   ingress above will not 403 itself. Current allow-list value:

     HIMMY_STUDIO_ALLOW_HOSTS={{ include "himmy-studio.allowHosts" . }}

   If you front the Studio with an additional proxy/CDN, add that hostname to
   .Values.studio.allowHosts and ensure the proxy forwards the original Host
   header (e.g. nginx: proxy_set_header Host $host;).
{{- else }}
   Port-forwarding uses a localhost Host header, which is always allowed.
   If you later add an ingress or external proxy, put its hostname in
   .Values.studio.allowHosts (ingress hosts are added automatically).
{{- end }}
